How I approach design

From problem to interface

01
Understand

Clarify the problem, intended users, and the task the product should help them complete.

02
Structure

Organize information into a clear hierarchy and map the main user journey before polishing visuals.

03
Design

Create consistent screens with deliberate typography, spacing, color, and reusable components.

04
Refine

Review the flow for clarity, accessibility, and responsive behavior; iterate where the experience feels confusing.

This describes my intended design approach; project-specific research, testing, and outcomes are included only where I have actually completed them.
